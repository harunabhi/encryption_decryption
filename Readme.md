# 🔐 Flask Encryption App

A simple web-based encryption/decryption app built with Flask and Python. Users can register, log in, input messages, and securely encrypt/decrypt them using AES encryption (via the `cryptography` library). All message history is stored and viewable in the user dashboard.

## 🚀 Features

- User Registration & Login
- AES-based Encryption and Decryption
- Per-user Secret Key Generation
- Message History Dashboard
- Session Management
- Flash Messaging for Errors (e.g., Invalid Login)
- Responsive UI with Professional Styling
